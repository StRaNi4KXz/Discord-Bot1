# Установка бота

## Что нужно загрузить на хостинг

Загрузи **содержимое** этой папки (`artifacts/discord-bot/`) на хостинг:
- `dist/index.js` — собранный бот (главный файл)
- `package.json`
- `src/` — исходники (не обязательно, если dist уже есть)
- `data/` — папка со статистикой (если переносишь с другого сервера)

## Переменные окружения

Создай файл `.env` или добавь в панели хостинга:

```
DISCORD_TOKEN=твой_токен_бота
DISCORD_REPORT_CHANNEL_ID=1527281622997667860
DATA_DIR=./data
```

## Команды

| Что делает | Команда |
|---|---|
| Установить зависимости | `npm install` |
| Запустить бота | `node --enable-source-maps dist/index.js` |
| Пересобрать (после изменений) | `npm run build` |

## Настройки панели хостинга (Pterodactyl и аналоги)

- **Install command:** `npm install`
- **Start command:** `node --enable-source-maps dist/index.js`
- **Node.js версия:** 18 или новее

## Папка data/

Бот хранит статистику в папке `data/`:
- `stats.json` — статистика участников
- `history.json` — история недель
- `dynamic_config.json` — настройки нормы

Папка создаётся автоматически при первом запуске.
Если переносишь с Replit — скопируй папку `data/` чтобы сохранить статистику.
